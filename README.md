# Практична робота №16

Тема: Особливості обробки подій зміни стану об'єкту.

## Реалізовано

- `radioOn` і `radioOff` під екраном калькулятора.
- Подія `CheckedChanged` для перемикання стану калькулятора.
- При `ON` усі кнопки активні і `KeyPreview = true`.
- При `OFF` усі кнопки вимкнені, `KeyPreview = false`, екран очищається.
- Подія `TextChanged` для `lblDisplay`.
- Колір тексту змінюється за довжиною:
  - 0-3 символи: чорний;
  - 4-8 символів: темно-зелений;
  - більше 8 символів: темно-червоний.

## Git

У репозиторій не треба додавати `bin/`, `obj/`, `.vs/`.
